# Practa Splash Screen

Drop in a `splash.png` for a branded fade animation before your practa loads.

---

## For Template Designers (Practa Template Repo)

> **Context:** You're building a practa in the template repo. There is no `build.json` here - that's generated later by the publishing pipeline.

### What You Need To Do

**Add one file:**

```
your-practa/
  ├── index.tsx
  ├── metadata.json
  └── assets/
      └── splash.png    ← Add this file
```

**That's all.** No other changes required.

### Image Requirements

| Property | Requirement |
|----------|-------------|
| File name | `splash.png` (exact name, lowercase) |
| Location | `assets/` folder |
| Aspect ratio | 1:2 (e.g., 1080 × 2160) |
| Format | PNG |

The image displays **edge-to-edge**, anchored to the top. Overflow clips from the bottom, never the top. This ensures branding/content at the top of the image is always visible.

### How It Works

The asset system handles everything automatically:
- **In template**: Assets load from your local `assets/` folder
- **After publishing**: Practa Manager uploads to CDN, Stellarin reads from there

You don't need to think about CDN or `build.json` - just add the file and it works.

If you don't add `splash.png`, no splash screen is shown. Your practa loads immediately.

---

## For Stellarin App Implementation

> **Context:** You're working in the Stellarin app codebase. Community practa arrive with a `build.json` containing CDN asset URLs, generated by the publishing pipeline.

### Asset Discovery

When the fetch script imports community practa, it reads `build.json` and copies asset URLs into the registry:

```typescript
import { getCommunityPractaBySlug } from "@/practa/community-loader";

const entry = getCommunityPractaBySlug("daily-sudoku");
const splashUrl = entry?.assets?.splash;
// → "https://cdn.example.com/splash.png" | undefined
```

### FlowScreen Integration

Add splash state and detection to FlowScreen:

```typescript
// In FlowScreen.tsx - existing imports
import { getCommunityPractaBySlug } from "@/practa/community-loader";

export default function FlowScreen() {
  const { currentFlow } = useFlow();
  const { practa } = useCurrentPracta();
  
  const [showSplash, setShowSplash] = useState(true);
  
  // Get splash URL from community practa registry
  const splashUrl = useMemo(() => {
    if (!practa) return null;
    const entry = getCommunityPractaBySlug(practa.type);
    const url = entry?.assets?.splash;
    // Guard: resolver returns "" for missing keys
    return url && url.length > 0 ? url : null;
  }, [practa?.type]);
  
  // Reset splash state when practa changes (any step in flow)
  useEffect(() => {
    setShowSplash(true);
  }, [practa?.id]);
  
  // Show splash if current practa has one
  const shouldShowSplash = showSplash && splashUrl !== null;
  
  return (
    <View style={styles.container}>
      {shouldShowSplash ? (
        <PractaSplashScreen
          splashImage={{ uri: splashUrl }}
          onComplete={() => setShowSplash(false)}
        />
      ) : null}
      
      {/* Practa content */}
    </View>
  );
}
```

### PractaSplashScreen Component

```typescript
interface PractaSplashScreenProps {
  splashImage: ImageSourcePropType;
  onComplete: () => void;
  displayDuration?: number; // default: 2000ms
}

export default function PractaSplashScreen({
  splashImage,
  onComplete,
  displayDuration = 2000,
}: PractaSplashScreenProps) {
  const [imageLoaded, setImageLoaded] = useState(false);
  
  // Timeout fallback: if image doesn't load in 5s, complete anyway
  useEffect(() => {
    const timeout = setTimeout(() => {
      if (!imageLoaded) {
        console.warn("Splash image failed to load, skipping");
        onComplete();
      }
    }, 5000);
    return () => clearTimeout(timeout);
  }, [imageLoaded, onComplete]);
  
  // Animation runs after image loads (see original proposal for full code)
  // ...
}
```

**Rendering:** Full-screen, anchored to top:

```typescript
const styles = StyleSheet.create({
  image: {
    width: "100%",
    height: "100%",
    resizeMode: "cover",
    position: "absolute",
    top: 0,  // Anchor to top, clips bottom
  },
});
```

**Animation sequence:**
1. White overlay fades in (300ms)
2. Splash image fades in (400ms)
3. Holds for `displayDuration` (2000ms)
4. Everything fades out (400ms)
5. Calls `onComplete()`

### Edge Cases

| Scenario | Behavior |
|----------|----------|
| No splash in registry | `splashUrl` is null, splash skipped |
| Empty string from resolver | Guard catches it, splash skipped |
| Image fails to load | 5s timeout calls `onComplete()` |
| Multi-practa flow | Each practa with splash shows its own |
| Practa changes | `showSplash` resets via `practa.id` dependency |
| Built-in practa | No registry entry, splash skipped |
